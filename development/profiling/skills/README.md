# Profiling Skills

Profiling skills describe agent workflows that build on the committed
`development/profiling` tooling.

Available skills:

- `snippet_extraction/SKILL.md`: create an isolated profiling target from a
  function, snippet, module, or line range.
- `trace_analysis/SKILL.md`: export supported Nsight reports, interpret host and
  GPU-projected timing separately, and report results with run provenance.
