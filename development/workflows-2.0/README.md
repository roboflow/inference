# Workflows 2.0 development examples

Runnable examples for the explicitly imported V2 engine in
`workflows/roboflow_workflows/execution_engine/v2/`.

| Examples | What you can try |
| --- | --- |
| [Passive foundation](01-passive-foundation/README.md) | Nested image crops, mosaics, conditional filtering, custom blocks, invalid bindings and metadata measurements |

Run commands from the repository root with `PYTHONPATH=workflows`. Each example
directory contains its code, workflow definitions and usage instructions.
